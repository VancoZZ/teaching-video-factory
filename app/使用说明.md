# 课程工厂 · 使用说明

一个把「上传的资料」变成「你的声线讲解视频」的桌面程序。
配音使用你在教学视频工具包里配置好的声线克隆（F5-TTS，本机 GPU），无需联网、无需付费。

## 打包内容

| 文件 | 说明 |
|---|---|
| 课程工厂.exe | 主程序（双击运行） |
| lessonlib.py | 动画引擎（必须与 exe 同目录，生成视频时自动复制到工程） |
| 课程工厂_配置.json | 首次运行后自动生成，保存你的设置 |

## 两段式流程（可拆开用）

**① 上传 → 逐字稿**（Tab 1）
- 把 Word / PDF / TXT / MD 或 **图片** 拖进窗口（支持拖整个文件夹，自动收集并去重）；
- 点「① 生成逐字稿」：AI（或本地模板）按资料产出**带标记符号的逐字稿**；
- 逐字稿在文本框里可直接编辑，点「校验格式」检查；「保存逐字稿」导出 .md、「加载逐字稿」导入。

**② 逐字稿 → 视频**（Tab 2）
- 直接使用 Tab 1 的逐字稿（或「加载逐字稿」导入的文件），点「② 生成视频」：
  自动完成 分镜 → 配音（你的声线，按标记控制语气/停顿/发音）→ 校验 → 渲染 → 成片；
- 视频出来后还能「调整视频…」：改某一幕读白、改语速重配、或让 AI 按需求重写后重渲。

两个模块**互相独立**：只要逐字稿，不用生成视频；只有逐字稿文件，不传资料也能直接出片。

## 逐字稿标记符号（写在【读白】行内）

| 符号 | 作用 |
|---|---|
| `**重点**` | 放慢语速并加重音量（讲结论/答案/关键数字） |
| `!!逐字!!` | 一字一顿（极重要的短语，如最终答案、口诀） |
| `[停0.8]` | 停顿 0.8 秒 |
| `[音:卷=倦]` | 发音替换：合成时读「倦」，字幕仍显示「卷」（多音字必写，如试卷的卷） |

- AI 生成的逐字稿会自动带标记；本地模板也会给关键句加 `**重点**`；
- 标记只影响配音，字幕自动显示干净文本；
- AI 生成多音字处理示例：`[音:卷=倦]`，常用读音（卷子）通常四声，AI 会自动标注。

## AI 对话框（对话式修改，直接对接 API）

主界面底部有**对话框**：目标选「逐字稿」或「视频」，输入需求回车。

- **目标=逐字稿**：配 AI Key 后，任何文字修改需求（「把第2幕语气更活泼」「每幕加一个提问」）
  由 AI 直接改逐字稿并回填编辑框，格式不合规会保留原稿并报错；
- **目标=视频**：本地指令（免 Key）——`语速改到0.8`、`删除第3幕`、`在第2幕后加一页总结：…`、
  `修改第2幕读白为：…`、`画质 h`、`重新配音`、`重新渲染`、`打开输出文件夹`、`帮助`；
  配 AI Key 后由 AI 理解生产类任务并自动执行。

## 大文件（整本书）支持

- 大 PDF 按页提取并显示进度，超过 800 页 / 30 万字自动截断（防卡死）；
- 扫描版/图片型 PDF 提不出文字时会明确提示（走 AI 读图或换文字版）；
- 所有错误都会弹窗显示，不再出现「没反应」。

## 图片（拍题/截图）生成视频 —— 需要 AI Key

拖入 PNG/JPG 等图片后点「① 生成逐字稿」，程序调用 AI **视觉模型**读图
（题目文字、图象、表格都识别）自动产出带标记的逐字稿。

**⚠️ 备注（重要）**：
- 图片读题**必须配置 AI API Key**（本地没有 OCR）——在「设置」→ AI 设置里填写；
- 模型必须是**支持视觉的**，例如：`gpt-4o` / `gpt-4o-mini`、`qwen-vl-plus` / `qwen-vl-max`、
  `glm-4v` 等；默认的 deepseek-chat **不支持图片**，用图片时请改模型名；
- 最多取前 4 张图片，每张自动压缩到 1500px 以内（JPEG）再上传，控制流量。

## 设置（首次使用前检查）

在「设置」页确认（保存到 exe 同目录的 json，下次不用再填）：

- **教学视频工具包路径**：默认 `D:\视频生成\教学视频工具包`（里面要有 .venv 和 .venv-tts）
- **声线参考音频**：默认 `...\声线参考\clean_24k.wav`（本任务的声线）
- **语速**：默认 0.85（越小越慢）
- **画质**：m=720p（推荐）/ h=1080p（约慢 4 倍）/ l=480p（最快）

## AI 设置（可选）

- 不填 API Key 也能用：本地模板生成逐字稿 + 全部本地指令 + 配音渲染全流程；
- 填入 API Key 后：AI 撰写带标记逐字稿、对话式修改、AI 配音导演（OpenAI 兼容接口）：
  - API 地址：如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`
  - 模型名：如 `deepseek-chat`、`gpt-4o-mini`
  - 点「测试 AI 连接」验证。Key 保存在本机 json，不上传任何服务器。

## 已知边界

- 图片（PNG/JPG）暂无法本地识别文字：需配 AI Key 走读图，或另附 Word/PDF/TXT；
- 拖拽用的是 Windows 原生消息（ctypes 实现），若拖拽无效请用「添加文件」按钮；
- 渲染依赖本机已有的教学视频工具包环境；换电脑需先在那台机器上部署工具包；
- 生成的视频默认 720p30。需要 1080p 发布版，在设置里把画质改成 h 重新生成。
